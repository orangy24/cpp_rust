# Your folder

`topics/` is the course katas. **This folder is yours** — questions you write down, and code you try without touching the course stubs.

```
practice/
  QUESTIONS.md     # the list (check boxes as you go)
  sandbox.cpp      # throwaway main(); ./run practice-sandbox
  tests.cpp        # Catch2 cases you add; ./run practice
```

Add a question: put a line in `QUESTIONS.md`, then either sketch it in `sandbox.cpp` or add a `TEST_CASE` in `tests.cpp`.
